# Zoo Management System

A Java-based project demonstrating object-oriented programming (OOP) through a simple zoo management system. The project models different animal types and their behaviours using classes and interfaces.

## Features

- **Animal Classes:** Represents different animals, including dogs, birds and fish.
- **Object-Oriented Design:** Uses inheritance and class relationships to organise the code.
- **Interfaces:** Implements `Flyable` and `Swimmable` to represent different animal capabilities.
- **Zoo Management:** Uses a `Zoo` class to organise and manage animal objects.
- **Testing Documentation:** Includes supporting documentation for testing the application.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)

## Getting Started

1. Clone or download this repository.
2. Open the project in a Java-compatible IDE, such as IntelliJ IDEA or Eclipse.
3. Ensure a compatible Java Development Kit (JDK) is installed.
4. Compile the source files and run `Main.java`.
